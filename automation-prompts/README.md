# 如何更新两个 Cursor 定时任务 Prompt

打开 https://cursor.com/automations ，分别用以下文件全文替换 Prompt 并保存：

| 任务 | 粘贴文件 |
|------|----------|
| 盘中实时简报（A股实时简报） | `PROMPT_盘中实时简报_可粘贴.txt` |
| 晚间深度简报（A股半导体简报） | `PROMPT_晚间深度简报_可粘贴.txt` |

## 当前模块

1. 近两日 Memories  
2. 宏观政策 / 国际形势 / 机构资金  
3. 资金流入 → 资讯 → 续涨确定性 → 上行时间窗  
4. 全市场公告清单 + AI/重点深挖 → 业绩推断  
5. 模型厂商发布 → 上下游 → **实际股价** → 港股/A股涨跌可能  
6. 长鑫每日跟踪（附录 A）  
7. **虚拟账户：50 万人民币 + 港股通 + 创业板/科创板**；严格交易规则；简报后更新记账；亏损复盘调策略；**每次输出最近一周滚动盈亏与操作总结**  
8. 发信纪律：每轮 1 封终稿；失败不写进正文  
9. 不限制总字数与新闻条数  

## 虚拟账户要点

- 初始/口径 500,000 元；若 Memories 仍为 10 万口径：现金 +400,000，**持仓不变**，只增资一次  
- 已开通港股通、创业板、科创板权限  
- 交易时段内可模拟成交；非交易时段只更新市值 + 写下一时段意向委托  
- A 股 T+1、涨跌停、手数（含科创板数量规则）；港股通标的/汇率/时段  
- 每轮输出：操作明细 + 实时/收盘重估后的完整账户快照 + **【最近一周盈亏与操作总结】**（滚动 7 个自然日：周初/当前净值、已实现与浮动、收益率与回撤、按标的贡献、盈亏各最多 3 笔、下周改进点；Memories 固化 weekly_* 台账）  
- **风格激进、高风险偏好**：单票默认上限 50%（极强可 60%–70%），总仓位目标 90%–100%；「不确定」可小仓试错，中性偏续及以上积极开仓；默认满仓出击、高换手，亏损以止损换股再布局为主，禁止长期空仓
